# 📘 DanMeok 韩语单词学习网站

一个覆盖 TOPIK 5426 个核心词汇的韩语学习工具，支持学习、复习、测验、进度追踪。

在线地址: [https://danmeok.pages.dev](https://danmeok.pages.dev)

## ✨ 主要功能

### 📖 单词背诵
- 按套装（每套 20 词）循序渐进学习
- 卡片式翻转设计，点击卡片查看释义
- 内置韩语语音朗读（原生 TTS + Google TTS 双重保障）
- 支持键盘快捷键，无需鼠标即可完成整个学习流程

### 🔁 艾宾浩斯复习计划
- 基于艾宾浩斯遗忘曲线自动安排复习
- 复习周期：1、2、4、7、15、30 天
- 首页清晰显示待复习数量

### 🎯 测验与拼写
- **选择题测验**：四选一，检验词义理解
- **拼写测验**：根据中文释义输入韩文单词
- **听力测验**：🎧 播放韩语发音，选择正确中文释义
- 三种测验模式：今日学习 / 初级专练 / 中级专练 / 全部混合
- 测验进度自动保存，刷新或退出后可继续

### ⭐ 收藏分类管理
- 自定义分类收藏单词（如「水果」「动物」「旅行」等）
- 分类列表视图，按类别集中复习
- 分类内快速切换（下拉菜单直接跳转其他分类）
- 单词详情页支持一键收藏/移出分类

### 📝 错题集
- 测验/拼写/听力错误自动收录
- 错题专项复习，掌握后自动移除
- 错题复习进度自动保存，刷新后继续

### 📅 学习日历
- 查看每日学习记录（新学 / 复习 / 掌握）
- 纯数字统计卡片（新学 / 复习 / 掌握）
- 彩色圆点标记不同学习类型

### 📊 进度追踪
- 首页环形图展示整体学习进度
- 词汇总览页按状态筛选（未学习 / 待复习 / 今日已学 / 永久掌握）
- 支持按等级（初级/中级）和关键词搜索
- 进度导出/导入备份，换设备不丢数据

### 🔍 单词详情页
- 点击任意单词查看完整信息
- 显示学习历程时间线（首次学习 / 每次复习 / 彻底掌握）
- 支持收藏/移出收藏

### 🌙 夜间模式
- 一键切换日间/夜间模式
- 适配暗色环境学习
- 偏好自动保存到本地

### ⌨️ 键盘快捷键

| 快捷键 | 功能 |
|:---|:---|
| `空格` | 翻转卡片（拼写模式下 Enter 提交答案） |
| `R` | 再看一次（延后复习） |
| `M` | 本轮记住 |
| `P` | 彻底掌握 |
| `V` | 朗读单词 |
| `C` | 收藏 / 取消收藏 |
| `←` / `→` | 收藏本翻页 |
| `Esc` | 返回首页 |

> 💡 快捷键在学习/复习/收藏本/错题复习/拼写页面生效

## 🛠 技术栈

## 🚀 本地运行

```bash
# 克隆项目
git clone https://github.com/Zzx-LiU6/topik.git
cd topik

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```

## 📦 数据持久化

所有学习进度、收藏、错题均存储在浏览器的 `localStorage` 中，无需登录即可使用：

| 存储键 | 内容 |
|:---|:---|
| `topik_word_progress_v3` | 单词学习进度 |
| `topik_current_set_v3` | 当前学习的套装 |
| `topik_bookmarked_words_v3` | 收藏单词列表 |
| `topik_wrong_words` | 错题列表 |
| `topik_quiz_state` | 选择题测验进度 |
| `topik_spell_state` | 拼写测验进度 |
| `topik_listen_state` | 🎧 听力测验进度 |
| `topik_wrong_review_state` | 错题复习进度 |
| `topik_dark_mode` | 夜间模式偏好 |

支持**进度导出/导入**，可跨设备迁移学习数据。

## 🗂 词库来源

单词数据来自 **TOPIK 官方词汇列表**，共 5426 个核心词汇，按等级分为初级（1-91 套）和中级（90-272 套）。
