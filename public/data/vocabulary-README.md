# vocabulary.json 词库编写指南

## 文件位置
```
public/data/vocabulary.json
```

---

## 标准模板（完整示例）

```json
{
  "1": [
    { "id": "1-1", "korean": "안녕하세요", "roman": "annyeonghaseyo", "meaning": "您好", "pos": "感叹词", "exampleKr": "안녕하세요, 만나서 반갑습니다.", "exampleCn": "您好，很高兴见到您。" },
    { "id": "1-2", "korean": "감사합니다", "roman": "gamsahamnida", "meaning": "谢谢", "pos": "动词", "exampleKr": "도와주셔서 감사합니다.", "exampleCn": "谢谢您的帮助。" }
  ],
  "2": [
    { "id": "2-1", "korean": "학생", "roman": "haksaeng", "meaning": "学生", "pos": "名词", "exampleKr": "저는 대학생입니다.", "exampleCn": "我是大学生。" }
  ],
  "40": [
    { "id": "40-1", "korean": "例子", "roman": "ye-ja", "meaning": "例子", "pos": "名词", "exampleKr": "이것은 예입니다.", "exampleCn": "这是一个例子。" }
  ]
}
```

---

## 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| id | **是** | 唯一标识，格式 `套装号-序号`，如 `40-1`、`40-20` |
| korean | **是** | 韩文单词（不得为空） |
| roman | 否 | 罗马音，缺失时显示空 |
| meaning | 否 | 中文释义，缺失时显示「待补充」 |
| pos | 否 | 词性，缺失时显示「词性未知」 |
| exampleKr | 否 | 韩语例句 |
| exampleCn | 否 | 例句中文翻译 |

---

## 套装编号规则

- **支持范围**: 1 ~ 40（或更多）
- **可以不连续**: `"1"`, `"3"`, `"7"`, `"40"` 可以同时存在
- **键必须是字符串**: 用双引号包裹数字，如 `"40"` 而非 `40`
- **程序自动识别**: 新增套装无需修改 JS 代码

## JSON 语法坑（绝对不能犯错！）

### 1. 最后一个元素后不能有逗号

```json
// 错误 - 数组最后一个元素后有逗号
"1": [
  { "id": "1-1", ... },
  { "id": "1-2", ... },  ← 这里多了逗号！
]

// 正确
"1": [
  { "id": "1-1", ... },
  { "id": "1-2", ... }
]
```

### 2. 最后一个套装后不能有逗号

```json
// 错误 - 最后一个套装后有逗号
{
  "1": [...],
  "2": [...],  ← 这里多了逗号！
}

// 正确
{
  "1": [...],
  "2": [...]
}
```

### 3. 所有键必须用双引号

```json
// 错误
{ 1: [...] }           ← 数字键没引号
{ '1': [...] }         ← 单引号不行

// 正确
{ "1": [...] }
```

### 4. 字符串值必须用双引号

```json
// 错误
{ "korean": '안녕' }    ← 单引号不行

// 正确
{ "korean": "안녕" }
```

### 5. 不能有注释

```json
// 错误 - JSON不支持注释
{
  // 这是第40套    ← 不允许注释！
  "40": [...]
}

// 正确 - 纯数据
{
  "40": [...]
}
```

### 6. 特殊字符需要转义

```json
// 如果释义包含双引号，需要转义
{ "meaning": "他说\"你好\"" }  ← 转义双引号用 \"
```

## 快速新增整套词汇的步骤

1. 打开 `vocabulary.json`
2. 找到最后一个套装的结束位置（`]` 后面）
3. 在 `]` 后面加一个逗号 `,`
4. 换行，添加新套装：

```json
  "40": [
    { "id": "40-1", "korean": "韩文", "roman": "romaja", "meaning": "释义", "pos": "词性", "exampleKr": "例句韩文", "exampleCn": "例句中文" },
    { "id": "40-2", "korean": "韩文2", "roman": "romaja2", "meaning": "释义2", "pos": "词性", "exampleKr": "例句韩文2", "exampleCn": "例句中文2" }
  ]
```

5. 检查：新套装前一个套装的 `]` 后要有逗号，新套装的 `]` 后不能有逗号（除非不是最后一个）
6. 保存文件
7. 刷新页面验证

## 容错机制

程序具备以下容错能力：

| 情况 | 处理方式 |
|------|----------|
| 单词缺少 `meaning` | 显示「待补充」 |
| 单词缺少 `roman` | 显示空 |
| 单词缺少 `pos` | 显示「词性未知」 |
| 单词缺少 `exampleKr/exampleCn` | 不显示例句区域 |
| 单词 `korean` 为空或缺失 | **该单词被跳过** |
| 单词 `id` 格式错误 | **该单词被跳过** |
| 整个套装非数组 | **该套装被跳过** |
| JSON 格式错误 | 显示错误提示，不白屏 |
